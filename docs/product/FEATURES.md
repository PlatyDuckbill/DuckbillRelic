# 기능 범위와 판정 규칙

상태: 기획 합의 (2026-11-10). 구현 전이며 실기 확인 결과는 없다.

## 범위

현재 출시된 모든 레릭을 다룬다. KR·글로벌이 같은 패치이므로 두 지역 모두 같은 범위다.

| 구분 | 계열 |
|---|---|
| 무기 (6) | 고대의 무기, 아니마 웨폰, 에우레카 웨폰, 레지스탕스 웨폰, 맨더빌 웨폰, 팬텀 웨폰 |
| 도구 (5) | 장인 도구, 하늘강철 도구, 찬란한 도구, 모웬 도구, 우주 도구 |

계열별 대상 직업 수와 단계 목록은 [GAME-DATA](../research/GAME-DATA.md#계열별-단계와-직업별-업적)를 따른다.

## 기능

1. **직업별 진행 표시**: 계열마다 직업×단계 표로 완료·다음 목표·미완료를 보여준다.
2. **자동 판정**: 아래 규칙으로 완료 단계를 정하고, 판정 근거를 칸 모양과 상세 문구로 구분한다.
3. **수동 표시**: 자동으로 확인할 수 없는 단계는 사용자가 "여기까지 완료"를 표시한다. 자동 판정과 섞지 않고 따로 저장한다.
4. **단계 상세**: 단계 퀘스트 진행, 필요 재료·보유·남은 수, 단계별 진행(황도 12문서 등)을 보여준다.
5. **남은 재료 합산**: 목표(직업·계열·목표 단계)를 고르면 남은 재료와 교환에 드는 석판·길을 합산한다. 캐릭터당 1회 재료는 해금 퀘스트를 마쳤으면 뺀다.
6. **명시적 클릭 동작**: 교환 NPC 위치를 지도에 표시하는 정도만 제공한다. 이동·구매·교환은 자동화하지 않는다.

## 완료 판정 규칙

한 직업·계열의 도달 단계는 아래 값 중 가장 높은 단계다.

| 근거 | 언제 읽히나 | 표시 |
|---|---|---|
| 레릭 보유 | 장착·병기고·소지품은 항상. 집사·초코보 가방·투영대는 사용자가 연 시점 값을 저장 | 보유 확인 / 마지막 관찰 |
| 직업별 업적 | 사용자가 업적 화면을 열어 클라이언트가 목록을 받은 뒤 | 업적 기록 |
| 수동 표시 | 사용자가 직접 표시 | 수동 |

- 도달 단계보다 낮은 단계는 완료로 추론한다(상위 단계 추론).
- 업적을 아직 불러오지 않았으면 업적으로만 알 수 있는 칸은 "확인 대기"로 두고 미완료와 구분한다.
- 수동 표시는 자동 판정이 따라잡아도 지우지 않는다. 화면에는 자동 근거를 우선 표시한다.
- 모조(복제) 무기·도구는 별도 아이템이므로 진행으로 세지 않는다.
- 퀘스트 기록은 계열 해금·진행 중인 단계·캐릭터당 1회 재료 판정에만 쓴다.

## 자동으로 알 수 없는 것

- 고대의 무기 2~8단계는 직업별 업적이 없다. 레릭을 넘겼거나 버린 직업은 수동 표시가 필요하다.
- 장인 도구·찬란한 도구는 업적 분류가 없다.
- 넥서스 빛, 팬텀 지식 크리스탈, 우주 도구 연구 데이터는 구조 조사 전까지 입력칸으로 둔다. [CLIENT-STATE](../research/CLIENT-STATE.md#조사-필요).
