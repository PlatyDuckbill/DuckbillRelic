# 기능 범위와 판정 규칙

상태: 기획 합의 (2026-11-10, 같은 날 자료 재검증 후 개정). 구현 전이며 실기 확인 결과는 없다.

## 범위

현재 출시된 레릭 무기 전부와 업적이 있는 레릭 도구 3계열을 다룬다. 장인 도구·찬란한 도구는 뺐다(2026-11-10 결정). KR·글로벌이 같은 패치이므로 두 지역 모두 같은 범위다.

| 구분 | 계열 |
|---|---|
| 무기 (6) | 조디악 웨폰, 아니마 웨폰, 에우레카 웨폰, 레지스탕스 웨폰, 맨더빌 웨폰, 팬텀 웨폰 |
| 도구 (3) | 하늘강철 도구, 모웬 도구, 우주 도구 |

계열별 대상 직업 수와 단계 목록은 [GAME-DATA](../research/GAME-DATA.md#계열별-단계와-직업별-업적)를 따른다. 우주 도구는 업적이 붙는 큰 단계 4줄만 보여주고 연구 데이터 세부 진행은 게임 화면에 맡긴다.

## 기능

1. **직업별 진행 표시**: 계열마다 직업×단계 표로 완료·다음 단계·미완료·모름을 보여준다.
2. **자동 판정**: 아래 규칙으로 완료 단계를 정한다. 판정 근거는 상세 패널에 한 줄로만 보여준다.
3. **수동 표시**: 자동으로 확인할 수 없는 단계는 사용자가 "여기까지 완료"를 표시한다. 자동 판정과 섞지 않고 따로 저장한다.
4. **판정 정정**: 자동 판정이 틀렸을 때 상세 패널에서 "이 관찰 기록 지우기"와 "수동으로 낮추기"를 쓸 수 있다.
5. **단계 상세**: 단계 퀘스트 진행, 필요 재료·보유·남은 수, 단계 안 진행(황도 12문서 등)을 보여준다.
6. **남은 재료 합산**: 목표(직업·계열·목표 단계)를 고르면 남은 재료와 교환에 드는 석판·길을 합산한다.
7. **명시적 클릭 동작**: 교환 NPC 위치를 지도에 표시하는 정도만 제공한다. 이동·구매·교환은 자동화하지 않는다.

## 완료 판정 규칙

한 직업·계열의 도달 단계는 아래 값 중 가장 높은 단계다.

| 근거 | 언제 읽히나 | 저장 |
|---|---|---|
| 레릭 보유 | 장착·장비함·소지품은 항상. 초코보 가방·집사·환상의 옷장은 사용자가 연 시점 | 본 적 있는 가장 높은 단계만 누적 저장 (보유 확인 / 마지막 관찰) |
| 직업별 업적 | 켜진 비트는 항상. 꺼진 비트는 사용자가 업적 화면을 열어 목록을 받은 뒤 | 달성 기록 저장 (업적 기록) |
| 수동 표시 | 사용자가 직접 표시 | 수동 |

- 판정은 계열 단계 **아이템 ID 허용 목록**으로만 한다. 모조·일반 장비(행성기술자 톱 등)는 목록에 없어 저절로 빠진다.
- 관찰과 업적 기록은 캐릭터별로 분리해 저장한다. **"있다"만 저장하고 "없다"는 저장하지 않는다.** 무기가 사라져도(강화 반납, 제타 반납, 판매) 기록을 낮추지 않는다. 낮은 단계 무기를 다시 사도 기록이 내려가지 않는다.
- 업적은 한 번 달성하면 사라지지 않으므로 받은 결과를 저장해 다음 접속에도 쓴다. 업적 목록을 아직 받지 않았고 저장된 기록도 없으면, 업적으로만 알 수 있는 칸은 "모름"으로 두고 미완료와 구분한다.
- 도달 단계보다 낮은 단계는 완료로 추론한다(상위 단계 추론).
- 나이트는 검 기준으로 판정한다. 방패는 상세에 따로 보여준다.
- 수동 표시는 자동 판정이 따라잡아도 지우지 않는다. 화면에는 자동 근거를 우선 표시한다.
- 퀘스트 기록은 진행 중인 단계·캐릭터당 1회 재료 판정에만 쓴다. 선행 퀘스트(해금) 표시는 보류(2026-11-10).

## 재료 합산 규칙

- 목표 단계까지 단계를 차례로 따라가며 합산한다. 이전 단계 무기를 요구하는 단계(팬텀 그림자~숨은그림자 등)는 그 무기를 재료로 표시한다.
- 캐릭터당 1회 재료는 해금 퀘스트를 마쳤으면 뺀다. 반대로 레지스탕스처럼 1회 퀘스트로 첫 무기를 무료로 받는 계열은, 그 퀘스트를 아직 안 했으면 무기 1개분 비용을 뺀다.
- 교환 단가와 화폐는 게임의 교환 목록에서 읽는다. 문서나 코드에 적어 두지 않는다.

## 자동으로 알 수 없는 것

- 조디악 웨폰 2~8단계는 직업별 업적이 없다. 제타를 아니마 재료로 반납하거나 무기를 버리면 보유 근거도 사라지므로, 플러그인이 본 적 없는 단계는 수동 표시가 필요하다.
- 아니마 1·2단계, 레지스탕스 보강된·법령, 팬텀 달그림자 등 ★가 없는 단계는 보유나 상위 단계 추론으로만 알 수 있다.
- 무기 안에 쌓이는 진행값과 키 아이템 진행은 읽지 못한다. 목록은 [CLIENT-STATE](../research/CLIENT-STATE.md#자동으로-읽을-수-없는-진행값). 재료 합산에 영향을 주는 값만 입력칸을 두고 나머지는 "게임에서 확인" 안내만 한다.
