# 화면 구성

상태: 목업 2차본까지 작성, 사용자 피드백 대기 (2026-11-10).

목업: [mockups/mockup-v2.html](../mockups/mockup-v2.html) — 브라우저로 열면 동작한다. 보유 개수와 자동·수동 출처는 설명용 가상 값이다.

## 합의한 구조

- 첫 화면은 **직업×단계 표**(원본 시트의 INDEX 탭과 같은 배치) + 오른쪽 **상세 패널**.
- 탭: 무기 / 도구 / 남은 재료.

## 구성 요소

**상단 상태 줄**
캐릭터 선택. 데이터별 마지막으로 읽은 시각(소지품 실시간, 초코보 가방·집사·투영대는 연 시점), 업적을 불러왔는지 여부.

**도구 막대**
"모든 직업을 끝낸 계열 접기", "시작한 계열만".

**직업×단계 표**
- 열: 직업(역할별 묶음). 행: 계열 제목 줄 + 단계 줄.
- 계열 제목 줄: 진행 막대·퍼센트, 직업별 도달 단계 숫자. 누르면 접힌다.
- 단계 이름 옆 파란 마름모: 직업별 업적이 있는 단계.
- 칸 모양: 보유 확인 / 상위 단계 추론 / 마지막 관찰 / 업적 기록 / 업적 확인 대기(?) / 수동 / 다음 목표 / 미완료. 해당 직업이 없는 칸은 점.
- 선택한 직업의 세로줄을 강조한다.

**상세 패널**
- 계열·단계, 직업별 레릭 이름(게임 데이터).
- 판정 상태와 이유 한 줄.
- 단계 퀘스트 진행(다음 목표일 때), 황도 12문서처럼 단계 안 진행이 있으면 막대.
- 필요 재료: "캐릭터당 1회"와 "무기마다"를 나눠 개수·보유·남음·보유 위치·교환 단가를 보여준다. 자동으로 못 읽는 값은 입력칸.
- 버튼: 끝 단계까지 목표에 추가, 여기까지 수동 완료(해제), 교환 NPC 지도.

**남은 재료 탭**
- 목표 목록(삭제 가능), 목표별 남은 단계 수.
- 요약: 석판 종류별·길 필요량과 보유량(주간 상한), 모자란 아이템 종류 수.
- 표: 석판 교환 / 길·기타 화폐 / 콘텐츠 보상 / 수동 입력으로 묶고, 1회 재료 배지와 쓰이는 목표를 표시.
