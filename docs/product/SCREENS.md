# 화면 구성

상태: 목업 3차본 작성, 사용자 확인 대기 (2026-11-10). 2차본 이후 자료 재검증과 사용자 결정(권장안 채택)을 반영했다.

목업: [mockups/mockup-v3.html](../mockups/mockup-v3.html) — 브라우저로 열면 동작한다. 처음 열면 첫 실행 상태(업적 기록 없음)다. 보유 개수와 진행 위치는 설명용 가상 값이다.

## 합의한 구조

- 첫 화면은 **직업×단계 표**(원본 시트의 INDEX 탭과 같은 배치) + 오른쪽 **상세 패널**.
- 탭: 무기 / 도구 / 남은 재료.
- 칸에는 **결과만** 보여주고, 판정 근거는 상세 패널과 "근거 표시" 토글로 본다. (2026-11-10 결정)

## 구성 요소

**상단 상태 줄**
캐릭터 선택. 데이터별 마지막으로 읽은 시각(소지품 실시간, 초코보 가방·집사·투영대는 연 시점), 업적 기록이 저장돼 있는지와 마지막으로 불러온 시각.

**업적 안내 줄**
업적 기록이 없을 때만 표 위에 보인다. "?" 칸의 뜻과 업적 화면을 한 번 열면 채워지고 저장된다는 안내.

**도구 막대**
"모든 직업을 끝낸 계열 접기", "시작한 계열만", "근거 표시".

**직업×단계 표**
- 열: 직업(역할별 묶음). 실제 화면은 게임 직업 아이콘 + 이름 툴팁(게임 데이터). 행: 계열 제목 줄 + 단계 줄.
- 계열 제목 줄: "완성 n/m"(끝 단계까지 마친 직업 수), 직업별 도달 단계 숫자. 업적 확인 전이면 "?". 누르면 접힌다.
- 단계 이름 옆 "업적" 배지: 직업별 업적으로 확인할 수 있는 단계.
- 칸 결과 5가지는 모양만으로 구분한다: 완료(채운 네모) / 다음 단계(빈 네모) / 미완료(점) / 모름(?) / 해당 직업 없음(어두운 빈 칸).
- 수동 표시로 완료한 칸만 모서리에 작은 원을 단다.
- "근거 표시"를 켜면 완료 칸에 근거 글자: 보(보유) · 관(마지막 관찰) · 업(업적) · 추(상위 단계 추론) · 수(수동).
- 탭 옆 숫자도 "완성 n/m"이다. 계열마다 단계 하나의 무게가 달라 %는 쓰지 않는다.
- 선택한 직업의 세로줄을 강조한다.

**상세 패널**
- 계열·단계, 직업별 레릭 이름(게임 데이터). 나이트는 검 기준이고 방패를 따로 표시.
- 결과와 근거 한 줄, 이유.
- 단계 퀘스트 진행(다음 단계일 때), 황도 12문서처럼 단계 안 진행이 있으면 막대.
- 필요 재료: "캐릭터당 1회"와 "무기마다"를 나눠 개수·보유·남음·보유 위치·교환 단가를 보여준다. 이전 단계 무기도 재료 줄로 보인다. 재료 합산에 쓰이는 무기 안 수치·게이지만 입력칸, 나머지는 "게임에서 확인" 안내.
- 우주 도구는 재료 대신 "세부 진행은 게임의 우주 연구 화면에서 확인" 안내.
- 버튼: 끝 단계까지 목표에 추가, 여기까지 수동 완료, 교환 NPC 지도.
- 판정 정정(틀렸을 때): 이 단계부터 수동 표시 해제 / 이 단계부터 미완료로 낮추기 / 이 관찰 기록 지우기 / 낮춘 판정 되돌리기.

**남은 재료 탭**
- 목표 목록(삭제 가능), 목표별 남은 단계 수. 업적 확인 전인 목표는 "업적 확인 대기"로 표시하고 합계에서 뺀다.
- 요약: 화폐별 필요량과 보유량, 모자란 아이템 종류 수, "합계에서 빠진 것" 건수.
- 표: 석판 교환 / 길·스크립 / 콘텐츠 보상 / 직접 입력으로 묶고, 1회 재료 배지와 쓰이는 목표를 표시.
- 석판 상한 문구는 게임 데이터로 확인하기 전까지 넣지 않는다.
