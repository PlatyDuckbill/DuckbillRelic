# 화면 구성

상태: 목업 4 "A 최소" 방향으로 결정 (2026-11-10). 세부 확인 대기.

목업: [mockups/mockup-v4.html](../mockups/mockup-v4.html) — 브라우저로 열면 동작한다. 위쪽 비교 막대에서 A 최소 / B 중간, 첫 실행 / 업적 화면을 연 뒤 장면을 바꿔 볼 수 있다(비교 막대는 실제 화면에 없음). 보유 개수와 진행 위치는 설명용 가상 값이다.

## 원칙

- 정보는 최소로. 칸에는 결과만, 판정 근거·데이터 시각·범례는 상세 한 줄과 도움말(?)·툴팁으로.
- 용어와 이름은 게임 표기를 따른다. 계열 이름, 단계 행 이름 규칙, UI 용어는 [GAME-DATA](../research/GAME-DATA.md#범위와-표시-용어-2026-11-10-결정).

## 구성 요소

**위쪽 한 줄**
탭(무기 / 도구 / 남은 재료), 오른쪽에 캐릭터 선택과 도움말(?) 버튼. 도움말에는 칸 모양 설명과 마지막으로 읽은 정보(소지품·장비함 실시간, 초코보 가방·집사·환상의 옷장은 연 시점, 업적)를 둔다.

**업적 안내 줄**
업적 기록이 없을 때만 한 줄: "업적 기록이 없어 일부 단계를 확인하지 못했습니다. 게임에서 업적 화면을 한 번 열어 주세요."

**직업×단계 표**
- 열: 직업(실제 화면은 게임 직업 아이콘 + 이름 툴팁). 역할 묶음은 얇은 세로선으로만 나눈다.
- 계열 줄: 계열 이름과 완성 직업 수(예: 1/10). 누르면 접힌다.
- 단계 줄: 번호 + 게임 접미어. 공통 접미어가 없는 단계는 사용자가 정한 이름(고대의 무기·조디악·새로운/강화된/진정한 아니마·레지스탕스).
- 칸 결과 5가지, 모양만으로 구분: 완료(채운 네모) / 다음 단계(빈 네모) / 미완료(점) / 확인 전(?) / 해당 직업 없음(어두운 빈 칸). 직접 완료 표시한 칸만 모서리에 작은 원.
- 칸에 마우스를 올리면 직업·레릭 이름·결과·근거를 툴팁으로.
- 선택한 직업의 세로줄을 강조한다.

**상세 패널**
- 직업 · 계열 · 단계, 제목은 그 직업의 실제 레릭 이름(게임 데이터).
- 상태 한 줄: 결과 + 짧은 근거(예: "장비함에서 확인", "업적으로 확인", "윗 단계가 확인되어 완료").
- 다음 단계일 때 단계 퀘스트 진행 한 줄.
- 필요 재료: 아이템 / 필요 / 보유. 보유가 충분하면 초록, 모자라면 금색. 캐릭터당 1회와 무기마다를 작은 소제목으로 나눈다. 보유 위치·단가는 툴팁. 직접 입력이 필요한 값만 입력칸.
- 우주 도구는 재료 대신 "세부 진행은 게임의 우주 연구 화면에서 확인" 한 줄.
- 버튼: [목표에 추가]와 [⋯]. [⋯] 메뉴에 여기까지 완료로 표시, 교환 NPC 지도에 표시, 판정이 틀렸다면(여기부터 미완료로 고치기 / 이 확인 기록 지우기 / 여기부터 직접 표시 해제 / 고친 판정 되돌리기).

**남은 재료 탭**
- 목표 목록(삭제 가능), 목표별 남은 단계 수. 업적 확인 전인 목표는 "업적 확인 전"으로 표시하고 합계에서 뺀다.
- 화폐별 필요량 / 보유.
- 표 하나: 아이템 / 필요 / 보유 / 남음. 많이 모자란 것부터. 1회 재료는 작은 배지, 쓰이는 목표·단가는 툴팁.
- 합계에서 빠진 것이 있으면 한 줄로 알린다.
