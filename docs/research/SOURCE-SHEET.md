# 원본 시트

출발점은 커뮤니티 Google 시트 "고대무기&도구 시트"다. 작성자는 세피르@모그리다(연락처는 시트 INFO 탭에 있음). 2026-11-10에 사용자 사본을 읽었고, 시트 버전 표기는 6.55.01이다.

## 사용 조건

시트에 "사본을 배포하지 마세요. 원본 게시글 링크를 전달해주세요"라고 적혀 있다.

- 설명문·팁·단계 설명·구성을 플러그인이나 공개 문서에 옮기려면 **작성자 허락**을 받는다.
- 필요 수량 같은 게임 사실은 게임 데이터나 다른 공개 자료로 별도 검증해 쓴다.
- 허락 여부는 아직 정하지 않았다 ([STATUS](../STATUS.md)).

## 구조 (9개 탭)

| 탭 | 내용 |
|---|---|
| INFO | 사용법, 업데이트 내역, 작성자 |
| INDEX | 직업×단계 완료 표(체크한 값이 그래프로 표시) |
| 고대의 무기 · 아니마 웨폰 · 에우레카 웨폰 · 레지스탕스 웨폰 · 맨더빌 웨폰 | 단계별 퀘스트 흐름, 직업 체크, 재료표(개당·총합·보유·필요) |
| 하늘강철 도구 · 모웬 도구 | 단계별 제작·채집 납품 재료와 직업 체크 |

- 재료표의 필요량은 `MAX(총합 − 보유, 0)`으로 계산하고, 총합은 개당 × 남은 직업 수다.
- 팬텀 웨폰·우주 도구·장인 도구·찬란한 도구는 시트에 없다.
- 시트의 흐릿한(회색) 단계는 두 번째 무기부터 생략되는 단계라는 뜻이다. 플러그인에서 캐릭터당 1회 재료를 구분하는 근거와 같은 개념이다.
