# 실행 중 읽을 수 있는 상태

조사일: 2026-11-10 · 근거: [FFXIVClientStructs](https://github.com/aers/FFXIVClientStructs) `eef1b79fe0c366acf3e58bf5fc2dbdbd89f9ba74`(2026-11-09), [Dalamud](https://github.com/goatcorp/Dalamud) `a74096043b58d69b08af214ac724f3d42c3a238b`(2026-11-04), Allagan Tools 공용 라이브러리 [CriticalCommonLib](https://github.com/Critical-Impact/CriticalCommonLib) `41374060`. 구현 착수 시 실행 중 KR·글로벌 Dalamud 배포판의 ClientStructs로 다시 확인한다. 실기 확인은 아직 없다.

| 대상 | 구조 | 조건·한계 |
|---|---|---|
| 업적 완료 | Dalamud `IUnlockState`(`IsAchievementListLoaded`, `IsAchievementComplete`, 해금 이벤트), ClientStructs `Achievement` | **켜진 비트는 언제나 완료.** 이번 세션에 새로 딴 업적은 목록을 불러오기 전에도 켜진다. **꺼진 비트는 목록을 불러온 뒤에만 미완료**이고 그 전에는 모름이다. `IsAchievementComplete`의 false는 목록 상태를 확인하지 않으므로 모름으로 다룬다. 목록은 사용자가 업적 화면을 열 때 게임이 요청한다. 플러그인은 업적 요청을 보내지 않는다. Type 1 업적의 진행 수치는 서버 요청이 있어야 채워지므로 쓰지 않는다 |
| 아이템 보유 | 인벤토리(장착·병기고·소지품) | 항상 읽힘. 다만 로그인 직후 컨테이너가 아직 오지 않은 순간이 있으므로 "없음"은 관찰로 저장하지 않는다 |
| 초코보 가방·집사 | 해당 화면을 연 동안 | 연 시점 값을 관찰 시각과 함께 저장. 게임의 아이템 찾기 로컬 캐시(`ItemFinderModule`)에 집사별 아이템 ID가 있으나 갱신 시점이 불명확해 1차 구현에서는 쓰지 않는다 |
| 투영대 | `MirageManager` | 존을 이동하면 지워진다. HQ는 ID에 1,000,000이 더해지고, 세트 저장은 세트 아이템 ID로 들어가므로 펼쳐야 한다. 레릭이 계열·단계별로 들어가는지는 실기 확인 대기 |
| 옷장 | `Cabinet` | 여관에서 넣고 뺄 때만 불러온다. 대부분의 레릭 무기는 옷장 대상이 아니므로 판정 근거로 쓰지 않는다 |
| 아이템 플래그 | `InventoryItem.Flags`에 `Relic = 4` | 의미가 문서화돼 있지 않다. 무기 안에 쌓이는 진행값(빛·밀도 등)을 담는 필드는 없다. 단계별 Flags 값은 실기로 기록한다 |
| 퀘스트 | `QuestManager.IsQuestComplete` | 항상 읽힘. 반복 퀘스트는 "한 번 이상 완료"만 남고 직업·횟수는 없다. 고대의 무기 1단계처럼 직업마다 퀘스트가 다른 경우만 직업 구분 가능 |
| 황도 12문서 | `RelicNote` | 지금 진행 중인 책 1권만 담는다. 소스상 던전 i, 돌발 i+4, 리브 i+7 비트라 돌발 3과 리브 0이 겹칠 수 있지만, 시트상 돌발·리브가 각 3개(0~2)라 실제로는 겹치지 않는다. 비트 간격이 고르지 않으므로 칸별 실기 대조는 한다 |
| 콘텐츠 값 | `PlayerState.GetContentValue(key)` — 에우레카 원소 레벨(2~4), 보즈야 저항 계급(5), 초승달 지식 레벨(6·7) | 해당 콘텐츠 안에서만 채워질 것으로 추정. 진행 보조 표시 후보 |
| 우주 연구 | `WKSResearchModule` — 분석값 11×7, 직업별 현재·해금 단계, `IsLoaded` | 구조는 있으나 플러그인은 연구 세부 진행을 다루지 않기로 했다([GAME-DATA](GAME-DATA.md#우주-도구-연구-데이터)) |

## 판정 규칙에 주는 영향

- 보유 관찰은 **본 적 있는 가장 높은 단계**로 캐릭터별 누적 저장한다. 강화하면 이전 무기를 반납하고, 제타를 아니마 재료로 반납하거나 기본 무기를 다시 살 수 있으므로 무기가 사라져도 낮추지 않는다.
- 장인 도구 Lucis는 길로 살 수 있어 아래 단계 수행을 증명하지 않는다. 남은 재료는 0이므로 판정은 그대로 두고 상세에 안내만 한다.

## 자동으로 읽을 수 없는 진행값

보유 수로 셀 수 없고 구조도 알려지지 않았다. 재료 합산에 영향을 주는 값만 입력칸을 두고, 나머지는 단계 상세에 "게임에서 확인" 안내만 한다.

| 계열 | 진행값 |
|---|---|
| 고대의 무기 | 아니무스 책(한 번에 1권), 노우스 마테리아 주입 75개, 넥서스 빛, 제타 마하트마 |
| 아니마 | 각성 던전 10곳 순서, 진정한 단계 에테르 밀도, 룩스 토벌전 12개 |
| 에우레카 | 고유 로고스 액션 수 |
| 팬텀 | 그림자 단계 에테르 4색 게이지(마구반), 숨은그림자 지식 크리스탈 기억 8분류 |
| 하늘강철 | 초기 단계 NPC 납품 횟수 |

크리스탈 점토·환영 해제기·데미아트마는 일반 아이템이라 보유 수로 계산한다.

## 확인 대기 (실기)

- 업적 화면을 연 뒤 텔레포·인스턴스 진입·캐릭터 전환 후에도 목록을 불러온 상태가 유지되는지.
- KR Dalamud 배포판의 API 수준, 포함된 ClientStructs 버전, `IUnlockState` 유무.
- 단계별 레릭 무기의 `Flags` 값, 레릭의 투영대 보관 가능 여부.
- 황도 12문서 칸별 비트.
