## 원칙 (재검증에서 정함)

- **진행 판정은 계열별 단계 아이템 ID 허용 목록으로만 한다.** 모조품은 이름 규칙이 섞여 있어(접두·접미, "무광 모조"·"미완성 모조", 이름 끝 공백이 있는 49099 등, KR 이름이 "모조"로 시작하지 않는 것만 70개) 이름으로 거를 수 없다. 허용 목록에 없는 아이템은 저절로 빠진다.
- **단계 판정을 아이템 이름에서 추론하지 않는다.** 아니마 1단계 KR 이름에 "아니마"가 붙는 등 이름이 단계를 오해하게 만든다. 단계는 시트 행 번호나 퀘스트 스크립트 순서로 정한다.
- **교환 단가·화폐는 모든 계열에서 교환 목록 시트(SpecialShop)로 읽는다.** 구 레릭 석판은 패치마다 시학 등으로 바뀌었다.

## 범위와 표시 용어 (2026-11-10 결정)

- 도구는 하늘강철·모웬·우주 도구만 다룬다. 장인 도구(Mastercraft·Supra·Lucis)와 찬란한 도구(Resplendent)는 범위에서 뺐다. 아래 조사 기록은 참고로 남긴다.
- 계열 이름은 게임 표기를 쓴다: 조디악 웨폰(퀘스트 분류 `JournalGenre#88`, 업적 분류 63. 업적 분류 62의 KR 이름은 "고대 무기"), 아니마·에우레카·레지스탕스·맨더빌·팬텀 웨폰, 하늘강철·모웬·우주 도구(업적 분류 KR 이름).
- **단계 행 이름 = 번호 + 게임 아이템에 공통으로 붙는 접미어.** 직업마다 아이템 이름이 달라 공통 접미어가 없는 단계는 사용자가 정한 이름을 쓴다(게임 문구 아님): 조디악 1 "고대의 무기"(커르타나·자나디서…), 7 "조디악"(엑스칼리버…), 아니마 3 "새로운 아니마"(알마스…), 5 "강화된 아니마"(제후의 검…), 7 "진정한 아니마"(에티르…), 레지스탕스 1 "레지스탕스"(오너바운드…). 상세에는 그 직업의 실제 레릭 이름을 보여준다.

### 묶음 경계

- **아니마**: 1단계 퀘스트 67748의 보상은 13611 "오트클레르: 아니마"(IL170)이고, 업적 키 67750 "찬란한 아니마 웨폰"의 보상은 13223 알마스(IL210, 3단계)다. 업적 1406 이름도 3단계 무기 이름이다. 그래서 1·2단계(아니마·각성)는 업적으로 확인할 수 없다. `AnimaWeaponItem` 1~8행이 8단계 × 14칸(13직업 + 나이트 방패)이다.
- **에우레카**: 직업당 16종. 표시는 업적이 붙는 끝 아이템 기준 5묶음이다. 나이트 예: [17817 낡은 갤러틴 → 21942 → +1 → +2 → 21990 갤러틴: 아네모스](5) / [22925 파고스 → +1 → 22957 엘리멘탈 한손검](3) / [+1 → +2 → 24071 피로스 한손검](3) / [24643 히다토스 검 → +1 → 24675 안테아 → 24691 안테아: 에우레카](4) / [24707 안테아: 맞춤형](1). KR 이름 규칙이 단계마다 달라 이름으로 묶을 수 없다. 재료 합산은 16종 단위로 한다.
- **우주 도구**: 직업당 **20종**(`WKSCosmoToolClass` 1~11행 = 11직업, 행마다 단계 칸 20개). 목수 예: 시험형 v0.1~v0.8(45591~45668, 8종), 우주 톱 45679, 우주 v1.1~1.4(49009~49042), 외계 톱 49053, 외계 v1.1~1.2, 초공간 톱 49148, 초공간 v1.1~1.2, 별들의 톱 51778. 업적은 우주·외계·초공간·별들의 아이템 칸에 붙으므로, 묶음은 **업적 아이템에서 끝나는 4줄**로 한다(외부 자료의 Novice/Intermediate/Advanced/Expert 구분과 같다). 외부 자료의 "19"는 강화 횟수다([Cosmic Tools](https://ffxiv.consolegameswiki.com/wiki/Cosmic_Tools)).
- **나이트 방패**: 고대·아니마·에우레카·레지스탕스·맨더빌·팬텀은 나이트 방패가 따로 있다(아이템 칸 = 직업 수 + 1). 판정은 검 기준으로 하고 방패는 상세에 따로 보여준다.

## 우주 도구 연구 데이터

`WKSCosmoToolDataAmount#1`에 20단계 × 7종(I~VII) 요구치·상한이 있고 11직업이 이 한 행을 같이 쓴다. 예: I열 v0.8 2,200 · 우주 2,800 · 우주 v1.4 4,300 · 외계 4,700 · 초공간 7,100 · 별들의 9,500. 별들의 단계 7열: 9500/9500/9500/9500/5600/2700/1600. 7열 각각이 어떤 데이터인지는 아직 대응시키지 않았다.

플러그인에서는 큰 단계(4줄)만 보여주고 연구 데이터 세부 진행은 다루지 않는다. 세부 진행은 게임의 우주 연구 화면에서 보는 편이 쉽다(2026-11-10 사용자 결정).

## 재료 합산에 필요한 규칙 (외부 자료)

- 레지스탕스 첫 무기는 1회 퀘스트(69380)로 무료다. 두 번째 무기부터 비늘가루 4개가 든다. 1회 수집 과제도 두 묶음 있다([Resistance Weapons](https://ffxiv.consolegameswiki.com/wiki/Resistance_Weapons)).
- 맨더빌은 첫 무기도 재료가 든다. 현재 석판은 시학(6.4 이전 천문, 7.0 이전 인과)이다([Manderville Weapons](https://ffxiv.consolegameswiki.com/wiki/Manderville_Weapons)). 실제 화폐는 SpecialShop으로 확인한다.
- 모웬 도구 교환은 외부 자료상 제작자/채집가 스크립 750이다([Splendorous Tools](https://ffxiv.consolegameswiki.com/wiki/Splendorous_Tools)). 목업 2차본의 "백화 1,500"은 근거가 없다.
- (범위 제외 계열) 장인 도구 Lucis는 제작·채집 직업 하나씩 완성하면 나머지 직업은 길로 살 수 있다(Supra는 불가). 찬란한 도구와 고대의 무기 기본 무기·에우레카 낡은 무기도 다시 살 수 있다.
- 패치별 완화(아니마 3.38·3.57, 레지스탕스 5.57)가 있어 오래된 공략 수치는 틀릴 수 있다.
