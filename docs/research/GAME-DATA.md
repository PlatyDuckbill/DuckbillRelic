### 업적 조건 형식 (데이터 패턴에서 추정)

`Achievement.Type`·`Key`·`Data` 값의 패턴으로 추정했다. 공식 정의는 아니므로 구현 전에 ClientStructs·실기로 확인한다.

| Type | 패턴 | 예 |
|---|---|---|
| 6 | Key = 퀘스트 ID. 직업마다 퀘스트가 다르다 | 고대의 무기 1단계: 커르타나와 신성한 방패(Key 66656) |
| 2 | Data = 다른 업적 ID 목록(모두 달성) | 되살아난 고대의 무기 |
| 1 | Key = 카운터 ID, Data[0] = 목표치 | "고대의 무기: 노우스 중 하나 입수", 에우레카·우주 도구 직업별 업적 |
| 24 | Key = 단계 퀘스트 ID, Data에 ClassJob ID(19 나이트, 21 전사, 32 암흑기사, 37 건브레이커…) | 아니마·레지스탕스·맨더빌·팬텀·하늘강철·모웬 |

Type 24는 "그 직업으로 그 단계 퀘스트를 완료하고 입수"로 보인다. 직업 수 × 단계 수와 업적 수가 정확히 맞는다.

## 아직 안 한 조사

- 단계별 재료를 게임 시트(퀘스트 요구 아이템, SpecialShop)에서 직접 뽑기. 지금 재료 수치는 원본 시트와 위키 값이다.
- 계열·직업별 레릭 아이템 ID 전체 목록 추출.
- 관련 시트 내용 확인: `RelicItem`, `RelicNote`, `Relic3`, `Relic6Magicite`, `AnimaWeapon5*`, `ResistanceWeaponAdjust`, `MKDRelicGrowth2*`(팬텀 추정), `WKSCosmoTool*`(우주 도구).
