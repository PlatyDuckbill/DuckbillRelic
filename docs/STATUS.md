## 1차 구현 (2026-11-10)

- 범위: 무기·도구 진행 표(최소 화면), 상세(레릭 이름·결과·근거 한 줄), 도움말, 업적 안내 줄, 직접 완료 표시·해제. 재료·목표·집사·판정 정정은 2차 이후.
- 판정 근거: 장착·장비함(주무기·보조무기)·소지품의 레릭(공개 API `IGameInventory`), 직업별 업적(공개 API `IUnlockState`, 켜진 비트만 완료로 기록하고 목록을 받은 시각 저장), 직접 표시. 게임 내부 구조 직접 접근 없음.
- 저장: 플러그인 설정 폴더의 `characters/<캐릭터 ID>.json`. 본 적 있는 최고 단계·달성 업적은 줄지 않는다.
- 자료: `data/relic-catalog.v1.json` (생성 규칙은 [GAME-DATA](research/GAME-DATA.md#레릭-카탈로그-생성-2026-11-10)).
- 빌드: KR Dalamud 15.0.3.9 참조로 경고·오류 없이 빌드됨. **인게임 확인은 아직 없음.**

### 실기 확인 순서 (기대 결과)

1. `pwsh -File scripts/build.ps1` → 출력된 DLL 경로를 Dev Plugin Locations에 등록하고 플러그인을 켠다. `/dbrl`로 화면이 열린다.
2. 업적 화면을 열기 전: 표 위에 업적 안내 줄이 보이고, 갖고 있지 않은 레릭의 업적 단계 칸은 `?`이다.
3. 장비함에 레릭이 있는 직업: 그 단계까지 채운 네모, 툴팁·상세 근거 "장비함·소지품에서 확인". 아래 단계는 "윗 단계가 확인되어 완료".
4. 게임에서 업적 화면을 한 번 연다: 안내 줄이 사라지고 `?` 칸이 완료·다음 단계·미완료로 바뀐다.
5. 지역 이동·재접속 후에도 4의 결과가 유지된다(저장된 기록 사용, 도움말에 업적 기록 시각).
6. 칸 상세의 `⋯` → "여기까지 완료로 표시": 모서리 점이 있는 채운 네모로 바뀌고 재접속 후에도 남는다. "여기부터 직접 표시 해제"로 되돌아간다.
7. 다른 캐릭터로 바꾸면 그 캐릭터의 기록만 보인다.
