게임 데이터 조사 결과

KR(2026.10.06)·글로벌(2026.10.16) 클라이언트의 업적·아이템 시트를 같은 행 번호로 비교했습니다. 두 클라이언트에서 같은 행이 같은 업적·아이템을 가리킵니다. 파란 칸은 그 단계에 직업마다 따로 업적이 있다는 뜻입니다.

항상 자동으로 채워지는 것

  • 장착·병기고·소지품의 레릭 → 그 직업의 현재 단계, 그 아래 단계는 완료로 추론
  • 소지품·크리스탈·석판·고유 아이템 개수 → 재료 보유 수
  • 퀘스트 기록 → 캐릭터당 1회 해금 퀘스트를 마쳤는지, 지금 진행 중인 단계
  • 모조(복제) 무기는 별도 아이템이라 진행으로 세지 않음

해당 화면을 열어야 채워지는 것

  • 업적 → 업적 화면을 열면 불러옴. 파란 단계는 무기를 넘겼어도 직업별로 확인됨
  • 초코보 가방·집사·투영대 → 연 시점 값으로 저장하고 시각 표시

수동 입력이나 추가 조사가 필요한 것

  • 고대의 무기 2~8단계: 직업별 업적이 없음 → 무기 보유 또는 수동 표시
  • 넥서스 빛, 지식 크리스탈, 우주 도구 연구 데이터 → 구조 조사 필요, 그 전까지 입력칸
  • 교환 비용(석판 종류·가격) → 게임의 교환 목록에서 자동으로 가져올 대상
