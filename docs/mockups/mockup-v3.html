처음 열면 첫 실행 상태(업적 기록 없음)입니다. 칸에는 결과만 보이고, 판정 근거는 칸을 눌러 상세에서 보거나 도구 막대의 "근거 표시"를 켜서 봅니다. 단계 이름과 직업별 업적 단계는 게임 데이터 재검증 값, 보유 개수와 진행 위치는 설명용 가상 값입니다. 직업 머리의 한 글자는 실제 화면에서 게임 직업 아이콘과 이름 툴팁으로 바뀝니다.

게임 데이터 재검증 결과

KR(2026.10.06)·글로벌(2026.10.16) 클라이언트의 업적·아이템·퀘스트 시트를 같은 행 번호로 비교했습니다. 파란 칸은 그 단계에 직업마다 따로 업적이 있다는 뜻입니다.

항상 자동으로 채워지는 것

  • 장착·병기고·소지품의 레릭 → 그 직업의 현재 단계, 그 아래 단계는 완료로 추론
  • 한 번 본 단계는 캐릭터별로 저장. 무기를 넘기거나 버려도, 낮은 단계 무기를 다시 사도 기록이 내려가지 않음
  • 퀘스트 기록 → 캐릭터당 1회 해금 퀘스트, 레지스탕스 첫 무기 무료 여부
  • 진행은 단계 아이템 ID 목록으로만 판정 → 모조·일반 장비는 저절로 빠짐

해당 화면을 열어야 채워지는 것

  • 업적 → 업적 화면을 한 번 열면 불러오고 저장. 그 전에도 이번 접속에서 새로 딴 업적은 바로 반영
  • 초코보 가방·집사·투영대 → 연 시점 값을 저장하고 시각 표시. 투영대는 지역을 옮기면 비워짐

게임 화면에서 확인하거나 직접 입력하는 것

  • 고대의 무기 2~8단계: 직업별 업적이 없음 → 무기 보유 또는 수동 표시
  • 넥서스 빛·팬텀 에테르 게이지처럼 재료 합산에 쓰이는 값만 입력칸. 나머지(지식 크리스탈 등)는 "게임에서 확인" 안내
  • 우주 도구 세부 버전·연구 데이터 → 게임의 우주 연구 화면
  • 교환 비용(석판 종류·가격) → 게임의 교환 목록에서 읽음
